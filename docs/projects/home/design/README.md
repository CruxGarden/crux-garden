# Home design references

Original storyboard and leaner exploration supplied by the user. The 13 PNGs are preserved byte-for-byte with portable filenames; [provenance and SHA-256 values](provenance.json) record the originals. This is a small, finite versioned reference set, not a place for generated build output or personal screenshots.

Start with [visual identity](00-brief-visual-identity.png), [Home](04-home.png), and [leaner Home exploration](12-home-leaner-exploration.png). The remaining scenes provide the broader narrative. Hardware, services, photos, metrics and controls shown are illustrative. Lab/Field/Station scenes are future context, not additional active implementation projects.

## Visual direction

Content first; calm botanical glass surfaces; restrained iridescence for focus/selection/featured items; warm headings and readable functional typography; amber for attention; accessible keyboard/controller focus and responsive density. Home is roomy, Lab may be denser, Field makes offline state clear, Station focuses on creation. Shared Mood tokens own the actual rendered colors, typography, borders and motion.

The leaner image is an exploration, not an approved pixel specification. Do not turn every illustrated card into a required integration or fabricate health data to match it. See the [Home plan](../README.md) before implementing.
