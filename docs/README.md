# Crux Garden documentation

Project plans and code live together in this monorepo. `apps/` contains runnable application entries; `packages/` contains shared implementation; `docs/` contains plans, decisions, evidence and handoffs. A project plan is not necessarily a separate executable yet.

- [Gyro](projects/gyro/README.md): interactive 3D gyroscope AI persona prototype; seven editable states, four styles, simple shaded rings and optional audio.
- [Home](projects/home/README.md): everyday experience, [vision](projects/home/vision.md) and [13 visual references](projects/home/design/README.md).
- [Migrate](projects/migrate/README.md): current standalone tool in `apps/migration`; its internal path is historical, its display name is Migrate.
- [Lifecycle](projects/lifecycle/README.md): proposed reusable host/service management boundary.
- [Omarchy setup order](projects/lifecycle/omarchy-setup.md): recovery, backups, SSH, development, maintenance, controller Bluetooth, SDR/HDR/VRR, local AI and services.
- [Source audit/map](projects/source-map.md): where the earlier Home preview now lives and which plans are not yet implemented.
- [Task handoffs](handoffs/README.md), [agent transfer workflow](agents/workflow.md) and [architecture decisions](adr/README.md).
- [Current state](../NEXT-AGENT-HANDOFF.md), [roadmap](../ROADMAP.md), [architecture](architecture.md), [local API](local-api.md) and [verification history](verification.md).

The imported user briefs are reference context; current project plans, code and task authorization govern execution. No credentials, private host addresses or personal data exports are required to read or build this repository.
